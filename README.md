# EPO 
This repository contains the simulation protocols and some analysis data for the EPO project. 
All data is structured inside the 'Repository.zip'

 - **DSSP Average**: Secondary structure evolution and timeline data obtained via DSSP analysis
 - **Linear Interaction Energy outputs**: Data for conjugated epitope and all prepolymerization mixtures.
 - **Molecular dynamics protocols for**: EPO-receptor, EPO, free epitopes, epitope conjugated with linker and epitope surrounding prepolymerization mixtures.
